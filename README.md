# LINE Webhook Image Echo

LINE Messaging API の Webhook を受信し、ユーザーから送られてきた画像をそのまま返信する、PHP 1ファイルのシンプルなスクリプトです。

画像メッセージを受け取ると、LINE のサーバーから画像を取得して一時的に自サーバーの公開ディレクトリへ保存し、その公開 URL を使って同じ画像を返信します。署名検証付きで、共有サーバーでも動作する想定で作成しています。

## 特徴

- PHP 1ファイル（`webhook.php`）だけで動作し、ライブラリやフレームワークは不要
- Webhook の署名（`X-Line-Signature`）を検証し、正規の LINE からのリクエストだけを処理
- 画像メッセージ以外（テキスト、スタンプなど）は無視
- 保存した画像は1時間で自動削除（リクエストのたびに掃除するため cron 不要）
- 画像の形式を実際の Content-Type／中身から判定し、拡張子（`.jpg`／`.png`）を使い分け
- GD が使える環境では、LINE のプレビュー仕様（最大240×240・JPEG）に合わせたプレビュー画像を自動生成
- 設定はファイル先頭の書き換えでも、環境変数でも可能（下記参照）

## 動作の流れ

1. ユーザーが公式アカウントに画像を送る
2. LINE プラットフォームが `webhook.php` に Webhook（署名付き）を POST する
3. 署名を検証し、画像メッセージであればコンテンツ取得 API から画像をダウンロードする
4. 画像を `line_images/` に一時保存し、その公開 URL で画像メッセージを返信する
5. 保存から1時間を過ぎた画像は、次回リクエスト時に自動で削除される

## 必要なもの

- PHP 7.4 以上（cURL 拡張が有効なこと。プレビュー生成には GD 拡張があると望ましい）
- HTTPS で公開できるサーバー（Webhook URL と画像 URL はどちらも HTTPS が必須）
- LINE Messaging API のチャネル（LINE Developers コンソールで作成）

## ファイル構成

```
line-webhook-image-echo/
├── README.md
└── webhook.php      # 本体。これ1ファイルをサーバーに置く
    └── line_images/ # 実行時に自動作成される画像の一時保存先
```

## セットアップ

### 1. チャネルの情報を取得する

LINE Developers コンソールで Messaging API チャネルを作成し、次の2つを確認します。

- チャネルシークレット（「チャネル基本設定」タブ）
- チャネルアクセストークン（長期）（「Messaging API 設定」タブで発行）

### 2. 設定する

`webhook.php` 先頭の設定部分を自分の値に書き換えます。

| 設定 | 内容 |
|---|---|
| `$channelSecret` | チャネルシークレット |
| `$accessToken` | チャネルアクセストークン（長期） |
| `$publicBaseUrl` | 画像を公開する URL のベース（例: `https://あなたのドメイン/line_images/`） |

環境変数が使えるサーバーでは、コードを書き換えずに次の環境変数でも設定できます（環境変数が優先されます）。

| 環境変数 | 対応する設定 |
|---|---|
| `LINE_CHANNEL_SECRET` | `$channelSecret` |
| `LINE_CHANNEL_ACCESS_TOKEN` | `$accessToken` |
| `LINE_PUBLIC_BASE_URL` | `$publicBaseUrl` |

> チャネルシークレットとアクセストークンは秘密情報です。実値を入れたファイルを GitHub 等の公開リポジトリにコミットしないでください。

### 3. サーバーにアップロードする

`webhook.php` を HTTPS でアクセスできる場所にアップロードします。`line_images/` ディレクトリは初回リクエスト時に自動作成されるので、PHP から書き込める権限だけ用意してください。

### 4. Webhook URL を登録する

LINE Developers コンソールの「Messaging API 設定」で次を設定します。

- Webhook URL: `https://あなたのドメイン/webhook.php`（アップロード先の URL）
- 「Webhook の利用」をオン
- 検証ボタンで成功することを確認

### 5. 動作確認

公式アカウントに画像を送り、同じ画像が返信されれば完了です。

## 注意・セキュリティ

- 返信に使うため、画像は一時的に**公開 URL でアクセスできる場所**に保存されます。URL が分かれば誰でも見られる状態になるので、機密性の高い画像の取り扱いには注意してください（保存期間は既定1時間で、`webhook.php` の `$imageRetentionSeconds` で変更できます）。
- `line_images/` には初回実行時に `index.html`（一覧表示防止）と `.htaccess`（置かれたファイルのスクリプト実行を禁止、Apache 系のみ有効）が自動で置かれます。Apache 以外のサーバーでは、同様の設定をサーバー側で行ってください。
- 署名検証に失敗したリクエストには `400` を返して処理しません。
- 取得・保存・返信に失敗した場合は、PHP のエラーログに `[line-webhook]` 付きで記録されます（トークン自体は記録しません）。

## トラブルシューティング

| 症状 | 確認すること |
|---|---|
| Webhook の検証が失敗する | Webhook URL が HTTPS で外部から開けるか、`$channelSecret` が正しいか |
| 何も返信されない | 「Webhook の利用」がオンか、応答メッセージ等の設定と競合していないか、エラーログに `[line-webhook]` の記録がないか |
| 「画像の取得に失敗しました」と返る | `$accessToken`（長期トークン）が正しいか、サーバーから `api-data.line.me` へ接続できるか |
| 画像が返信されない・プレビューが出ない | `$publicBaseUrl` が正しく、保存された画像の URL が外部から開けるか（HTTPS 必須） |
| `line_images/` が作られない | `webhook.php` のあるディレクトリに PHP の書き込み権限があるか |
